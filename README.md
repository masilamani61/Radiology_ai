# RadiologyAI

RadiologyAI is an end-to-end chest X-ray classification and MLOps project. It combines a React frontend, FastAPI backend, PyTorch model pipeline, MLflow tracking, DVC reproducibility, Airflow retraining orchestration, and Prometheus/Grafana monitoring.
